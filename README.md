# Aventio Webinar Launch OS

Aventio's webinar launch checklist for every client: 103 tasks across 12 phases. Each task has a "what good looks like" standard, a KPI to check, an owner, a due date worked back from the webinar date, and notes. The Benchmarks tab grades each webinar and points to the bottleneck.

## Open it as an app

Live at `https://antoniohx777-sys.github.io/aventio-launch-os/` once GitHub Pages is on.

- **iPhone (Safari):** open the link → Share → Add to Home Screen
- **Android (Chrome):** open the link → menu → Install app
- **Mac (Safari):** open the link → File → Add to Dock
- **Mac (Chrome):** open the link → install icon in the address bar → Install

It opens full screen with its own icon and works offline after the first visit.

## Data

Progress saves on each device. To move it between devices: ••• → Back up all clients, then Import backup on the other device.

## Editing tasks

Everything is in `index.html`. The task library is the `PHASES` array and the benchmarks are the `BENCH` array near the top of the script. Edit, commit, and the installed app updates the next time it opens online.
